## Phần A — Kế hoạch kiểm tra, bảo trì jig/gá định kỳ

| STT | Mã jig/gá | Hạng mục kiểm tra | Tiêu chuẩn chấp nhận | Tần suất | Người thực hiện | Kết quả gần nhất (ngày) | Ghi chú |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | | | | | | | |
| 2 | | | | | | | |

Gợi ý hạng mục kiểm tra theo loại:

- **Jig/gá kẹp giữ:** độ mòn bề mặt định vị, lực kẹp, độ đồng tâm, khe hở, nứt/vỡ.
- **Khuôn (mold/die):** bề mặt form, hệ thống làm mát, pít-tông/xy lanh, thanh dẫn hướng, keo dính/bám bẩn.
- **Dao cụ:** độ mòn cạnh cắt, rung động khi cắt, tuổi thọ đạt giới hạn chưa.

Kết quả bất thường → xử lý như sự cố thiết bị ([[BM-TBSX-04 Sổ theo dõi bảo dưỡng sửa chữa thiết bị]]).

## Phần B — Chương trình thay mới dụng cụ nhanh hỏng (perishable tools)

| STT | Tên dụng cụ | Dùng cho máy/sản phẩm | Tiêu chuẩn thay mới | Tồn kho tối thiểu | Chu kỳ đặt mua | Nơi đặt mua | Người theo dõi |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | | | | | | | |
| 2 | | | | | | | |

**Tiêu chuẩn thay mới** chọn một cách đo rõ ràng, ví dụ:

- Theo số lần sử dụng (VD: mũi khoan thay sau 2.000 lỗ).
- Theo thời gian hoạt động (VD: dây curoa thay mỗi 6 tháng).
- Theo sản lượng (VD: đầu tiếp xúc thay sau 50.000 chu kỳ ép).
- Theo dấu hiệu vật lý (mòn đến vạch giới hạn, mất độ chính xác kích thước).

## Quy trình sử dụng

1. **Lập kế hoạch đầu kỳ** cho từng jig/gá trong [[BM-TBSX-09 Danh mục Jig, Gá và Dụng cụ sản xuất]], dựa trên khuyến cáo nhà cung cấp và kinh nghiệm hao mòn thực tế.
2. **Thực hiện kiểm tra** đúng tần suất, ghi kết quả; dụng cụ không đạt → sửa chữa hoặc đề xuất thay mới.
3. **Theo dõi tồn kho** dụng cụ nhanh hỏng: chạm ngưỡng tồn tối thiểu → phát đặt mua trước khi cạn.
4. **Đánh giá cuối kỳ** cùng [[BM-TBSX-03 Kế hoạch bảo dưỡng máy]] phục vụ đánh giá KPI và xem xét của lãnh đạo.
